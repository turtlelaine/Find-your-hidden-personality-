# Find-your-hidden-personality-
A satirical personality quiz that turns terms of service, cookies, and permissions into analog horror. A study in consent design and dark patterns. You'll get your unique personality type after the test, and might be losing some more.  

## Description  
  
This is a final project for the Technology and New Media Art class. The questionnaire starts with some normal question such as:  
`Q1. When there’s a chance to meet new friends, you tend to:`  
`Q3. Your favourite season:`  
`Q7. Are you more like a cat or a dog person?`  
  
And slowly became uncanny like:  
`Q6. Are you alert?`  
`Q？？. Will you choose option C in this question?`  
`Q10. Do you check everything for REAL?`

## How to run  
  
Just open `index.html` in a browser.  
  
For full functionality (camera, notifications, geolocation), serve it over localhost or a static host since some browsers block permission prompts on `file://` URLs.  
  
## Disclaimer

This is a satirical media art project. No data was actually collected, stored, or transferred. No organs will be harvested. Probably. :)
